# 可直接改写的生图提示词

以下是适合当前风格的工作模板，不是已经生成或验收的新设计。每次选择当前需要的一条，结合真实口播与素材，别把五种内容混成一张。共通委托放前，具体任务接后；参考图角色写清。所有“不要”针对已发生问题，不靠无限堆负面词替代设计任务。

## 共通设计委托

```text
请作为有成熟审美的专业平面设计师、课程视觉设计师，自主设计一张中文AI影视课程动效关键帧。你拥有构图、比例、尺寸、间距、分组、排版和光学调整的设计权。先理解这帧需要让观众看懂什么，再选择能解释内容的画面，不要仅把提供的词排成一行。

画幅为16:9横向，目标2K，交付完整单张关键帧，不是拼图、样机或网页截图。深近黑海军蓝背景，极克制的深紫和深蓝氛围，主体为同系列白色面型图形；必要时仅用一点浅紫强调。中文视觉接近苹方，保留正常笔画。

请运用留白、对齐、邻近、重复、对比、视觉等重与光学重心，建立简洁清楚的主次和阅读路径。主体适度，不横向铺满；图标、标签、组间距由你判断，不规定坐标、字号、固定占比或三等分。白色面型图标正视、圆角与负形统一，一眼能识别。一个主轮廓配必要负形，不套多层外框，不在图标内画四宫格、缩略图、小窗口、工具栏或每格重复小图案。

文字只保留指定短标签，图形必须承担解释意义。不要加总标题、副说明、英文、编号、标志或长句，不靠满屏纯文字呈现所有概念。不要玻璃、金属、渐变图标、立体挤出、强光、卡片套卡片、网格、粒子和装饰线。背景大面积平整连续，必要细节集中在主体，避免噪点、过度锐化和边缘光晕。保留观众能轻松看懂的画面。
```

这段不强迫所有课程内容必须用图标。当前段落需要真实作品/照片时，用实际素材替换图形部分，并明确身份、裁切及保真约束。

## A. 想法成为画面

```text
观看任务：让新手直观看到脑海里的想法可以成为画面。
必要内容：准确中文“想法”“画面”；用同系列的简单白色灯泡与照片面型符号承担两个概念。可以用一个克制的关系提示说明变化，是否需要、如何安排由你设计。照片符号只保留识别所必需的负形，不套外部窗口；两端视觉等重，不把灯泡或照片做得巨大。不再增加“输入”“输出”“AI创作”等说明词。
```

## B. 新手的疑问

```text
观看任务：让观众感受到从工具使用、模型选择到第一步实践的困惑，并能区分当前正在讲哪一问。
保留本段真正需要的短词，例如“用工具”“选模型”“先开始”“做专业视频”；以实际口播为准，不擅自改写原口播。为当前问题选择有明确含义、同系列的简洁对象，可采用依次聚焦的一组画面；不强求四项同时铺满，不生成一页全是问句的列表，也不加四个无关装饰图标。各图标内部尽量单层，不用小界面和多层按钮讲工具。
```

## C. 文字、图片、视频

```text
观看任务：展示三个同级创作媒介。仅包含准确中文“文字”“图片”“视频”和对应同系列白色面型文档、照片、视频符号。文档以极少量负形横条识别，照片以简单山峰/太阳负形识别，视频以简洁摄像或播放符号识别；不要文字用T、图片用玻璃山峰、视频用另一种立体三角。按专业设计判断光学大小，不强制同样外接框。充分留白，不加连接线，除非该段实际要表达流程关系。
```

这条已有明确认可整图可参考。复现时优先用包内分件，而不是每次重生另一套。

## D. 提示词四部分

```text
观看任务：让新手知道提示词由四个不同职责的部分组成，而不是只记四个名字。
必要短标签：“任务”“画面描述”“参考”“约束”。为四个职责设计统一、直白的白色面型符号，可以考虑任务/目标、画面、参考标记、锁定限制这类关系，但最终造型与构图由你判断，别把建议机械画成按钮。当前“任务”可有克制紫色强调。图形与短标签共同表达内容，不要只排四个词，也不要用复杂图中图、小任务清单、四宫格或大段提示词补充。允许按阅读节奏分组，不必强制同一横排。
```

## E. 写剧本、排分镜、做视频

```text
观看任务：让观众看懂助手依次组织三步制作工作。
必要短标签：“写剧本”“排分镜”“做视频”，配同系列简单白色面型符号。剧本可用一个文档轮廓及极少量负形横条，分镜用两张简洁画格或简洁胶片轮廓表达先后，不要每格再画山峰太阳、不要外面板套四个小框；视频用简洁摄像/播放符号。三者重量、圆角、负形和细节密度接近。关系提示只在解释先后时用，构图、位置、间距由你设计，不加入“Agent”“Skill”等额外说明和小字。
```

## F. 只改复杂的分镜图标

```text
这是局部修改。只将“排分镜”的图标简化为更清楚的同系列白色面型：一个主轮廓配少量必要负形，通过两张简单画格的关系或简洁胶片轮廓表达分镜；去掉外面板、四宫格、每格重复的山峰和太阳、小边框与按钮。保持原画面的其他图标、标签、总体构图、视觉大小、间距、深蓝紫背景和留白。不要把它换成细线框，不要放大，不改其他内容。
```

若生成改动波及其他元素，用原始认可稿与局部蒙版合成，不反复叠加整图。仅修改造型不等于新画面已验收。

## G. 透明分件与干净背景

透明分件：

```text
以认可关键帧中指定图标为造型依据，提取同一白色面型分件；保留轮廓、圆角、负形、光学大小和视觉重量。透明背景，保留真实Alpha和适度边距，不烘焙棋盘格或深色底；不新增渐变、阴影、光晕、底座或内部细节，不换形状。不要文字。用于按原稿还原动画。
```

背景：

```text
只移除前景图形与文字，恢复干净、连续的深近黑海军蓝背景，保留克制的深紫深蓝角落氛围和原有光线关系。不要新增符号、图形、框、噪点、粒子、纹理、网格和文字。背景用于分件动效，不能残留原图标或标签的影子。
```

## 调用记录模板

把完整实际提示词保存为工程 `design/片段编号.prompt.txt`，输入素材用途与真实工具回执保存成JSON。不要只保存这份模板文件名。目标2K不保证工具最终输出2K，读取文件尺寸；透明请求也须看实际Alpha。语义与构图由生图设计，运动由可编辑工程实施，不把关键帧自动当视频模型首帧。
