# 视觉语言

## 方向与取舍

优先采用最新认可的 `references/images/approved-imagegen-layout.png`：深蓝紫背景、小而清晰的白色面型图标、充足留白。飞书包装文档“修改”列保留为背景与历史风格参考，不覆盖用户后续明确选择。旧金色方案、此前浅紫卡片演示均非当前默认。深色画面不意味着堆科技装饰：质感可以来自干净形状、精确比例与留白，不要求每个元素都用玻璃、高光和透明度。

文档中的薄玻璃与极细轮廓属于历史风格参考，不覆盖当前白色面型默认。保留的是克制蓝紫气氛；不机械照抄对话框三圆点、菱形、点阵、圆环和层层边框。多元素同屏只突出当前讲解对象。

## 色彩起点

`assets/design-tokens.json` 是可调起点，不是逐像素锁死的色卡：近黑海军蓝约 #080B17，紫罗兰约 #8655E8，电蓝约 #4D50F3，青色约 #8DEDF2，白字约 #F4F1FF。白字是主要信息；蓝紫用于背景氛围或必要强调；当前概念图标采用白色面型，不默认加蓝紫渐变或青色描边。避免三种高饱和颜色平均分摊。

背景大面积保持深暗、平整、连续。角落光可非常柔和，但不要压低文字对比度。参考背景素材可复制到工程，比例改变时重新设计或裁切确认，不能直接拉伸。

## 字体与文字密度

本项目使用苹方简体。主信息通常中等或半粗字重，保留正常笔画，不斜切、不做大刀式尖角，不靠厚描边制造“花字”。字体不可用时先查用户提供的字体包或本机苹方；明确报告缺失，不能静默换成其他黑体。

画幅与输出分辨率是交付参数，不是预先决定字号的理由。图标、标签的比例由 imagegen 在完整画面中设计；认可后再测量还原。不默认90—120像素大字，不把每个关键词都做成巨型标题。以成片可读、层级清楚、视觉等重和充分留白为判断，不为统一字号挤压长词。

以下是删字顺序，而非补字清单：

1. 删除与口播同义的说明句，例如“从基础操作，到完整创作”。
2. 删除不帮助定位的课程编号、章节角标、品牌重复标志。
3. 删除解释图标的第二层解释；图标下的“图片”可保留，“图片节点用于生成图片”不保留。
4. 能用一组关系说明的，不加总标题。例如“工具讲解 → 案例实战”无需上面再写“课程分为两部分”。
5. 长知识点拆为顺序画面，不把字号缩成小字。

不是绝对禁止说明文字：确需逐项阅读、比较数值或引用时，按教学目的保留，并分屏给足时间。默认每屏只承担一个观看任务。

## 图形不能被减字一起删掉

2026-11-07的补充：少字不是只排一屏名词。概念、步骤与关系要用清楚的图形或真实素材解释，文字只负责必要短标签；不加无关图标填空。短标题、过渡和确需读字的引用可保留纯文字，具体取舍见 `visual-explanation.md`。

## 几何和层级

背景＋主信息＋必要强调即可；人物口播时再考虑真正必要的前后遮挡。不要把这个层数理解为所有工程只能有三条轨道。

重要字和图形须留足安全边距；不把固定占屏比例当成要求填满的内容区。对话框、玻璃片、全屏细框按需使用，不给每个字、每个图标都套框。图标不默认加统一方形按钮底座；如果符号自身需要取景轮廓，避免在轮廓外再套窗口。一个主轮廓与必要负形足够，不做四宫格里重复小风景、窗口内再嵌窗口。

## 这次认可的设计经验

大图标虽然清楚，却让画面过满。新版让 imagegen 自主设计后，文字由T改为文档符号，三个符号的圆角、负形和视觉重量更协调，主体整体收敛，空白参与构图。复用的是这种设计方法与视觉方向，不是把这组三项的具体排布锁定为所有镜头的模板。

新构图先看整张画面。不要将“不要太满”转成擅自指定40%、50%等数字，不强制居中等分；让设计师依据当前内容决定疏密与位置。原片、用户指定安全区等实际限制仍需如实交代。
