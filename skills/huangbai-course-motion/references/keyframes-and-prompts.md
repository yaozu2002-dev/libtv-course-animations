# 关键帧、素材与生图提示词

## 关键帧必须约束什么

新镜头先写一句“这帧让观众看懂什么”，提供必要内容与使用场景，把构图、比例、间距、排版和光学调整交给 imagegen。不要先替它决定具体布局，再要求它“像专业设计师一样设计”。用户给的参考先看原图，不凭图片的自动描述断定风格。

对于现有素材，优先用原片截图；人物身份、姿态和背景透视保持不变。教学作品取真实视频或原始图片；没有时可先用现有素材占位，记录占位用途，不宣称是真实完成的案例。

关键帧是视觉约束，不是把三宫格直接当成视频输入。这里以素材分件和可编辑动画为主；若走AI视频路线，遵守用户的资产参考偏好，不默认上传参考成片、拆帧或分镜拼图。

## 设计委托的写法

提示词分清三件事：

- **必须表达**：这段的观看任务、正确的关键词、画幅、品牌基调、人物/作品素材的实际约束。
- **设计原则**：清晰层级、充分留白、对齐与邻近、重复与对比、光学尺寸、重心、视觉等重和阅读节奏。
- **设计师自主决定**：主体尺寸、内容区宽度、位置、间距、分组与构图。不默认给像素、坐标、固定占比、强制居中或等分。

“作为专业设计师”应与明确的设计任务、决定权和判断原则一起使用；只加身份称号不能保证审美。设计稿仍须实际看图，不把方法写成效果保证。

## 新增两项检查

任何新任务都要说明：图形负责解释内容，不能只把概念词排上屏；白色面型应减少内部层级，不做大面板套四个小框、每框再有完整小图案。两项与原有留白、同系列共同成立。短标题可以纯字，不强制每屏配图标。详细改写示例见 [提示词实例库](prompt-recipes.md)。

## 已获认可的提示词示例

以下保留此次获认可的关键做法；按新镜头替换内容，不照搬三项布局：

> 请作为一位有成熟审美的专业平面设计师、影视课程视觉设计师，自主设计一张中文AI影视课程的动效关键帧。你拥有构图、比例、间距、排版和光学调整的设计决定权，不要仅机械执行三件图标平均放大的模板。
>
> 设计任务：简明展示“文字、图片、视频”三个同级创作媒介。包含对应的同一套白色面型图标和准确简体中文“文字”“图片”“视频”，文字视觉接近苹方。深海军蓝近黑背景，极克制的深紫与深蓝氛围，白色主体。交付完整16:9横向关键帧，目标2K，不要拼图或样机。
>
> 运用专业平面设计原则：建立清晰简洁的信息层级，用留白形成呼吸感；处理对齐、邻近、重复与对比，为不同轮廓做光学尺寸和重心校正，使图标视觉等重；图形与标签比例、距离适当，整体有疏密节奏与视觉平衡。图标比铺满画面的巨大图标小一些，文字不过大，内容不要横向铺满。具体布局、主体尺寸、内容区宽度、分组与位置由你判断，不规定坐标、像素、固定占比或强制平均三等分。
>
> 图标为同系列白色实心几何面型，圆角和细节语言一致，可用深色负形。允许重新设计符号轮廓以建立系列感，不必拘泥于T或现有图标。不做玻璃、金属、渐变图标、强发光或玩具感。不要总标题、副标题、小字解释、编号、英文或标志；不用外框、卡片套卡片、连接线、粒子、网格。背景平整连续，细节集中主体，避免噪点、过度锐化。交付经过整体权衡的最终设计画面。

此次结果见 `images/approved-imagegen-layout.png`；大主体反例见 `images/overfull-white-icons.png`。对比重点是主次、比例、间距、视觉等重与留白，不只是换颜色或缩放。

普通文字最终由真实苹方实现，保留认可稿的字号关系、位置、比例、行距与留白；先静态对照，再编排动作。不能在代码还原时重新随意设计一版。

## 从认可稿提取整组图标

先由 imagegen 设计整张画面，认可后再按同样造型、比例、圆角、负形和颜色生成/提取透明分件。当前默认白色面型；不沿用旧版半透明紫蓝玻璃提示词。整组图标保持一致，但不规定每个概念都必须套相同底座或同样外框。

拆件提示可写：

> 以已认可画面中的图标为造型依据，提取/生成同一套白色面型透明素材，保留符号轮廓、圆角、负形和视觉重量，不重新换造型、不放大、不加渐变、外框或装饰。各分件保留透明边距，不烘焙棋盘格。素材用于按原设计还原动效。

若单独分件生成导致造型漂移，回到原始认可稿做精确裁切/蒙版或有针对性的局部处理，不反复整图生成。新内容需要新图标时让 imagegen 在既有系列语言内设计，并与整组并排检查。

## 背景提示词示例

> 16:9深近黑海军蓝课程包装背景，90%以上区域深暗而连续平整；角落极轻微紫光和蓝光，中心适合放白色大字与紫蓝图形。不要文字、图标、外框、卡片、网格、点阵、粒子、圆环、烟雾或划痕；光照克制，不变浅紫色。

## 分件记录

为每项保留原图、透明分件、生成输入、提示词、实际尺寸与使用范围。未经检查的素材标为候选，不能默认为批准。

透明素材先检查真实Alpha；裁切时保留合理边缘和高光，避免过度阈值把玻璃透明区切成硬塑料。修边后在深浅底和最终尺寸复查。不要把粗暴抹掉阴影当作通用玻璃抠图方案。

目标2K是生成请求，实际分辨率以文件读取为准。背景和图标的实际源分辨率决定能放多大，不能用放大后的画布证明原生高分辨率。

## 在具备内置生图工具的环境中调用

先把提示词实例替换成当前任务，实际查看所用参考图，再调用当前提供的imagegen工具。以下为参数结构示意，**不是终端命令**；工具名字和受支持字段以当前环境展示的说明为准，不虚构尺寸字段或模型开关：

```json
{
  "prompt": "这里填写完整的设计委托与当前任务，不只填一个标题",
  "referenced_image_paths": ["当前工程中实际存在的参考图绝对路径"],
  "transparent_background": false
}
```

全新生成且不需要参考时，省略参考字段；目标是抠好的透明分件时将透明背景设为true。有本地路径就按工具支持的路径方式引用，只有对话图片而无路径时按该工具提供的对话图片机制选择，不能凭空填一个文件地址。工具要求先查看本地图时先查看。背景和完整关键帧通常不透明，分件才请求透明。

生成前在提示词里写明16:9、目标2K；工具若没有对应参数，不向接口塞额外键。生成后检查回执及实际文件，并复制到当前工程；核对文字、图标复杂度、主体尺度与留白。保存完整提示词、输入用途、原图和候选状态，后续局部修正不覆盖源文件。

没有内置image能力时，优先查当前环境已配置、已授权的等价生图工具，继续使用本包提示词与验收标准；不要把代码拼版当成等价审美探索，不要求读者复制作者的登录态或密钥。涉及接口密钥或额外计费时按实际工具规则处理，本包不分发账号和凭证。AI视频生成仍单独确认参数，不能因为生成过图片就自动开视频任务。
